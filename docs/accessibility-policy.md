# Accessibility policy (Fieldnotes knowledge base, v1)

Standard: WCAG 2.1 AA (the approved external bar for this workspace).

Every form field must have an accessible name: a programmatically associated
label, aria-label, or aria-labelledby. A bare input with no accessible name is
an accessibility failure (high severity in the QA charter) and blocks release.

The name field on the tenant profile form is in scope for this slice.
