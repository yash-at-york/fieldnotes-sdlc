# Kestrel

Local product shell for one signed story: manual referral capture (`P1-REQ-INT-01`, `STORY-S0-01`).

The screen to build has four fields: source, requested services, geography, and requested start date.

- Empty: those fields are empty and no saved summary is shown.
- Missing field: save names each missing field and does not show a saved summary.
- Complete save: the summary shows the four values.
- Failed save: the four entered values stay on the form.
